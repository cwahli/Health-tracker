   models in the catalog = 285/286 RED on any checkout without the #706
   one-line fix. Environmental, not a code regression. Any row whose gate
   includes bot-host must reckon with this (Health-08 did).
5. **agent-heartbeat loop mode exits immediately.** `setInterval(..).unref()`
   + bare `await new Promise(()=>{})` = empty event loop → node exits 0 after
   the first beat. The recorded pid is dead, so `isLive` reads false. REAL
   DEFECT, queued not fixed (forbidden): re-beat with `--once` every ~15 min
   for freshness; hygiene 7-day rule makes this safe for a same-day run.
6. **Proof PNGs: condense, don't screenshot raw scrollback.** Full assert
   output is ~1500 lines; the proof keeps `$ cmd` + summary lines
   (`696 pass, 0 fail`, `# fail 0`) + `exit=N` + RESULT, all real output,
   tagged `[condensed N lines -> M; full log retained on box]`. Filenames must
   not claim another ticket's number (`fileCardNumber` matches bug|card+N):
   use `<ref>-gate.png` (e.g. `health-03-gate.png`, `bug-01-gate.png` — own
   number matches, passes curation).
7. **sheet_row.rb review gate is the enforcer.** `--status review` aborts
   without a linked proof URL AND a non-empty Drive folder. Folder name must
   equal the row key (`proofFolderMap --createFor <key>`). `--note` must carry
   old text + appended stamp (byte-intact); untouched fields merge automatically.
8. **assert-sheet-proof may carry others' reds.** Auto-01 mislink FAIL is
   pre-existing, outside my ten — verify MY rows resolve, report others, don't
   touch them.
9. **Shell `${var##*:}` eats Drive key prefixes.** `Health-04:spec:DOCTOR-1`
   with `##*:` yields `DOCTOR-1`, and four proof folders were filed under
   prefix-stripped names (verifier: zero images). Fixed by Drive rename to the
   exact key (rename ≠ delete; each folder held only my PNG). RULE: pass keys
   as separate quoted vars, never split `ref:key` on `:`.

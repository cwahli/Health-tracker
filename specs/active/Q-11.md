# Packet Q-11 — App Shell Decoupling (umbrella)

**Unlocked 2026-09-17.** Owner: any agent. Design doc: `plan/APP_SHELL_DECOUPLING_PLAN.md`.

> **This file is the contract, not a work item** (`auto_go: false`). Work happens in the milestone
> packets below, one milestone per commit, one commit per module. Never execute two milestones in
> the same working tree — they all edit `src/App.tsx` and will collide.

## 1. Why this packet exists

`src/App.tsx` is a 9,101-line god file and the AI Studio transfer target, so splitting it is worth
doing. The first attempt (commit `a14abea`) did it by rewriting instead of moving: `src/types.ts`
559 → 26 lines of `export type X = any` (byte-identical to the stub `67da7ca` had reverted as the
forbidden AI Studio LOAD_HACK state), `AuthScreen.tsx` deleted, `onAuthStateChanged` / `fbSignOut` /
`clearCachedAppData` / `JobStore.resetAllJobs` gone, `translations.ts` 4,009 → 3,501 lines, 188 files
deleted including `CATALOG.json` — while passing `tsc`, `vitest` and `vite build`.

Its budget table also summed to 2,550 lines against a 9,100-line file, leaving ~72% of the monolith
unassigned: an executor obeying "no file exceeds 400 lines" had to stub or delete the remainder.
This packet replaces aspiration with measured budgets, per-milestone packets and enforcement.

## 2. Laws (apply to every milestone)

1. **Move-only.** Code moves; behaviour, names, exports and contracts do not change.
2. **No deletions.** A milestone adds files. If a deletion looks necessary, stop and re-scope.
3. **`src/types.ts` is frozen.** Nothing here requires touching it.
4. **Parity before and after.** `node scripts/assert-parity.mjs` must stay green; it fails on an
   `= any` type, a dropped i18n key, a deleted required file, an unreachable auth/identity
   capability, a raised CATALOG ceiling, a `@ts-nocheck`, or growth of `src/App.tsx`.
5. **Ratchet as you go.** When a file shrinks, lower its `CATALOG.json` ceiling in the same commit.
6. **Never edit a gate to pass it** (`@ts-nocheck`, gate deletion, baseline lowering via `--update`
   without a written justification in the packet).
7. **Stop after your milestone.** Run the gate list, report, hand back. Do not chain into the next.

## 4. Per-milestone definition of done

A milestone is done only when, in one commit:

1. Its packet gate list is green (`tsc`, `assert-parity`, `assert-budgets`, `journey-guard <id>`,
   `assert-spec-diff <id>`, the milestone's named vitest file, `assert-shell-smoke`).
2. `git diff --stat` shows a **move**: the new module's lines ≈ the lines removed from `App.tsx`,
   and no file outside `allowed_files` changed.
3. `src/App.tsx` is no larger than the "App.tsx after" column above.
4. `CATALOG.json` ceiling for every file that shrank is lowered in the same commit.
5. `plan/ROADMAP.md` and `AI_HANDOVER.md` get one line each.

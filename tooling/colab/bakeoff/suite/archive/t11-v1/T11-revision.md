# T11 revision (v1 -> v2): MTD quiz, page scroll + link/tile states

Date: 29 Oct 2026 (Europe/London, UTC+0).

## Diagnosis

- **Spec conflict (confirmed).** The v1 prompt and `quizcheck.js` demand a FULL-SCREEN quiz: panel at least 98% of the viewport wide, no border, no radius. The v1 reference, commit 15732a48, does that by deleting the panel's border and radius. The agreed Figma frame 3776:6405 (re-read this turn) is a centred box: the outer quiz body is 1520 wide, 40px padding, **40px radius, NO border and no fill** (chiwah removed the border in Figma); inside it, the "Gradient panel" is 1440 wide with **1px #5e5e5e border, #1b1b1b fill, 40px radius, 40px padding**. v1 asked for the opposite of the design, so a model that kept the box would fail "panel is a box (1232px wide)".
- **That conflict was not what failed the 18 runs.** All 18 attempts have an EMPTY final.diff (no_edit, no_edit_tool_errors, fake_success, or timeout). The quoted check reasons are simply the untouched seed state; the models never got far enough to be penalised for the conflict.
- **Prompt under-specified (also a cause).** Tile/close state values were hidden in the "original site" (computed CSS that a text web fetch cannot produce; stored in `suite/quiz/orig.json`). "the repo's link guideline" was never named. Three loosely related requirements were bundled with no stated target look.
- **MiMo ceiling runs mis-recorded.** MiMo r2 and r3 each had a 0-byte events.jsonl over about 30 minutes, a provider hang. They were logged as `timeout` fails instead of `unavailable` (which would have triggered the DeepSeek fallback). Treated as unavailable in the archive.
